# tdd 出力テンプレート

tdd スキル §6 結果出力から参照される出力テンプレート集。
Red-Green-Refactor サイクルの各 step ごとに該当テンプレートを使用する。

> **出力形式の絶対要件**：出力は **マークダウンとして直接レンダリングされる形で出力する**。出力全体を ` ``` `（トリプルバッククォート）で囲むことを禁止する。表・見出し・絵文字フェーズアイコン（🔴 / 🟢 / ♻️）が視認可能な状態でユーザーに表示される必要がある。
